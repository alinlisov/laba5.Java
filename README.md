#  Лабораторна 5: 

Проєкт присвячений роботі з базовими та декоративними потоками введення-виведення в Java (`java.io`), розробці кастомних потоків-фільтрів для шифрування даних, зчитуванню та аналізу вмісту вебсторінок за URL, а також об'єктній серіалізації.

---

##  Основний функціонал

1. **Аналіз текстових файлів (Завдання 1):**
   * Порядкове зчитування файлу та знаходження рядка з найбільшою кількістю слів.
2. **Кастомне потокове шифрування/дешифрування (Завдання 3):**
   * Реалізація алгоритму зміщення коду символів за допомогою кастомних декораторів `EncryptFilterWriter` та `DecryptFilterReader`.
   * Повна підтримка кодування `UTF-8` для коректної роботи з кирилицею.
3. **Аналіз та сортування HTML-тегів за URL (Завдання 4):**
   * Завантаження HTML-коду за довільним URL з підтримкою `HttpURLConnection` та `User-Agent` (захист від помилки `403 Forbidden`).
   * Пошук тегів за допомогою регулярних виразів.
   * Виведення результатів:
     * У лексикографічному порядку назв тегів (за зростанням).
     * У порядку зростання частоти їх використання.
4. **Серіалізація та збереження даних (Вимоги 1–6):**
   * Об'єктна серіалізація/десеріалізація результатів у файл за допомогою `ObjectOutputStream` та `ObjectInputStream`.
   * Клас-контейнер `TagCounter`, що імплементує `Serializable`.
   * Інтерактивне консольне меню з повною обробкою некоректного введення та шляхів (`try-catch`, очищення від лапок і пробілів).

---

##  Технологічний стек

* **Мова програмування:** Java 17+ (сумісно з Java 11)
* **Основні пакети та класи:**
  * `java.io`: `BufferedReader`, `BufferedWriter`, `FilterWriter`, `FilterReader`, `ObjectInputStream`, `ObjectOutputStream`, `Serializable`.
  * `java.net`: `URI`, `URL`, `HttpURLConnection`.
  * `java.util.regex`: `Pattern`, `Matcher`.
  * `java.nio.charset`: `StandardCharsets.UTF-8`.
